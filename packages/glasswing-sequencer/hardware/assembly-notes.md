# Glasswing Pattern Sequencer - assembly notes (Rev A)

1. Fit the main board first and inspect the power rails before fitting the
   controller board.
2. Torque the panel standoffs to 0.4 N m; do not over-tighten the copper panel.
3. Perform the offset trim described in the calibration procedure before the
   first audio test.

Revision Rev A is the current production build. Any earlier build notes have
been retired and are not part of this package.
