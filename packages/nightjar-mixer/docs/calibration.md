# Nightjar Eight-Channel Mixer - calibration

## Equipment

- 6.5 digit bench meter
- low-distortion audio analyser
- calibrated 1 kHz reference source

## Procedure

1. Warm the unit for 20 minutes.
2. Set the reference source to 1 kHz at -10 dBu and record the input offset.
3. Adjust the trim until the measured offset is below 0.5 mV.
4. Sweep the band edges and record the response in the production log.

The procedure applies to Rev C hardware only.
