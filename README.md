# Hollowpine Instruments - Workshop Repository

Source repository for the public Hollowpine Instruments product catalogue and
the released design packages.

- Catalogue entries live under `catalogue/entries/`.
- Released design packages live under `packages/<entry-slug>/`.
- Site chrome and generated assets are handled by the static site generator.
- When publishing entries, do not edit files outside `catalogue/entries/` and `notes/`.
- Published pages are regenerated from the `main` branch on every push.

Questions: catalogue@hollowpine-labs.example
